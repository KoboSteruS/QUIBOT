Дополнительные функции конфигурации в отличии от типовой версии 1С УНФ

Номенклатура (26)

  • Генерация уникального штрихкода номенклатуры с префиксом организации, например, MX12312312. Используется для создания единого штрихкода для разных маркетплейсов. (1)
  • Хранение и печать дополнительных штрихкодов для разных маркетплейсов. Используется, когда на каждом маркетплейсе используется свой ШК. (6)
  • Возможность автоматической генерации артикула номенклатуры по связке Бренд + Модель + Цвет (3)
  • Форма поиска использования номенклатуры в существующих спецификациях (2)
  • Документы качества. Хранение сертификатов соответствия и деклараций о соответствии в 1С с подробной информацией и “сканами” документов. Автоматическая привязка сертификатов к номенклатуре по связке Производитель + Состав + Тип документа качества. Возможность печати информации из сертификатов на этикетках на товары. (8)
  • Контроль заполнения всех необходимых полей в обработке печати этикеток. (2)
  • Отчет Цены номенклатуры - выводит по размерно все цены по указанному Виду цен. (2)
  • Автоматическая установка Закупочных цен номенклатуры по последней цене закупа. (2)

Производство (53)

  • Возможность указывать время операций в спецификациях в секундах (а не в часах). (10)
  • Маршрутные карты для производства. В маршрутных картах отражается порядок операций для производства изделий, сотрудники выполняющие операции наносят личные штрихкоды на маршрутную карту. После выпуска продукции бухгалтер сканированием подбирает документ производства и отмечает сотрудников, работающих над изделиями. Им начисляется зарплата по сделке. (16)
  • Упрощенная форма ввода сдельных нарядов с контролем плана по производству и ранее занесенных сдельных нарядов. (4)
  • Возможность планировать производство продукции по дням. Отчеты для сравнения плана и факта. (16)
  • Фиксация количества брака по сдельным нарядам по исполнителям/номенклатуре/типу брака. (3)
  • Отчет План/факт сдельных нарядов по документам Производство - позволяет проверить, что на всю произведенную продукцию заведены сдельные наряды. (2)
  • Отчет Себестоимость выпуска - сравнение с ценой (МИ) - позволяет сравнить полученную Себестоимость выпуска продукции с установленной ценой в 1С, например, с Нормативной себестоимостью. (2)

Склад (6)

  • Статусы Принят и Отгружен в документе Перемещения запасов. Для возможности без включения ордерной схемы своевременно списать товар с одного склада и принять на другом только после его реального поступления. При каждом проведении контролируются права сотрудников на склады на котором меняется остаток. (6)

Маркировка (23)

  • Возможность частичной печати кодов маркировки из заказа, не всех сразу. (2)
  • Печать штрихкода номенклатуры на этикетке с маркировкой, а не GTIN. (3)
  • Возможность работать (эмиссия, ввод в оборот) с кодами маркировки принадлежащим разным организациям, даже если в 1С используется одна организация. (6)
  • Контроль заполнения кодов маркировки при создании Расходной накладной. (2)
  • Возможность повторной печати выбранного кода маркировки. (2)
  • Контроль особых прав при проведении Списаний и Оприходований товаров. Права назначаются отдельно, например, только бухгалтерам. (2)

Продажи (5)

  • Автоматическое создание Расходной накладной при смене состояния Заказа покупателя в Отгружен/Завершен. (5)

Маркетплейсы (168)

  • Полный цикл работы с заказами Вайлдберриз по схеме FBS из 1С при сдаче поставок на Склад ВБ:
    • Поштучная сборка заказов
    • Групповая сборка заказов (одновременно собирается много заказов)
    • Сборка маркированных заказов
    • Печать стикеров на заказы 1С
    • Формирование и завершение поставок FBS с печатью ШК поставки
    • Отмена заказов FBS
    • Настройка ассортимента товаров для выгрузки остатков для продажи по FBS
    • Возможность работы с несколькими кабинетами по FBS одновременно (60)
  • Поставки по схеме FBO на Вайлдберриз и Озон
    • Документ Поставка хранит в себе состав каждой поставки, с количеством коробов, ШК коробов и ШК поставки.
    • Возможность через выгрузку/загрузку наполнять короба и сопоставлять их с ШК в ЛК Вайлдбериз и 1С.
    • Печать ШК коробов и ШК поставки из 1С для Вайлдберриз. (16)
  • Автоматическая еженедельная загрузка отчета реализации Вайлдберриз. (30)
  • Возможность загрузки отчет реализации Вайлдберриз из файлов, когда отчеты не возвращаются по API. (3)
  • Автоматическая загрузка отчета реализации Озон FBO. (30)
  • Обработка Расчет потребности на МП для Вайлдберриз. Получает остатки товаров на ВБ, продажи за последние 7 дней, исходя из этого считает среднедневное потребление и определяет сколько товаров нужно отправить на указанное количество дней. (24)

Закупки (10)

  • Возможность учета Кратности заказа и Минимального заказа на товары у поставщиков при оформлении Заказа поставщику. (4)
  • Вывод на печать Заказа поставщику в номенклатуре поставщика. (2)
  • Автоматический пересчет единиц измерения при печати Заказа поставщику в номенклатуре поставщика, если номенклатура в базе 1С и у поставщика учитывается в разных единицах измерения. Например, ткань в 1С учитывается в метрах, а поставщик ее поставляет в килограммах. (3)
  • Запрет проводить Приходные накладные без регистрации цен поставщиков. (1)

Персонал (36)

  • Возможность назначать сотрудникам, которые работают по сделке, Грейды и доплачивать премию в % от выполненной работы. (5)
  • Возможность назначать надбавку сотрудникам, которые работают по сделке, за изготовление “новинок”, товаров с которыми они еще не работали. Например, надбавка 10% за пошив первых 30 шт. платьев новой модели. (5)
  • Возможность автоматически назначать премию за переработки в зависимости от количества переработок. Например, по табелю сотрудник должен был отработать 160 часов, а по сдельным нарядам отработал на 200 часов. (24)
  • Добавлена возможность в документе Начисление зарплаты начислять ЗП по выбранной группе сотрудников (а не всем сразу). (2)

Дополнительно (31)

  • Возможность автоматической выгрузки платежных поручений в банк. (8)
  • Возможность автоматически разбирать полученные банковские выписки и создать документы - Расход со счета, Поступление на счет. (16)
  • Контроль работоспособности регламентных фоновых заданий 1С. В случае ошибок информация отправляется администратору на почту. (4)
  • Возможность подключаться к разным банкам через разные прокси-сервера. (3)

API (46)

  • Создание Расход из кассы, Поступление в кассу, Перемещение денег (16)
  • Поиск информации о контрагенте по ИНН (4)
  • Создание Платежного поручения (6)
  • Создание Отчета комиссионера о списании (4)
  • Получение цены номенклатуры по артикулу (4)
  • Получение информации по номенклатуре с остатками и ценами (12)
